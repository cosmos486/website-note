## 使用

直接打开 index.html 可浏览页面。在线托管时将 仓库根目录中的全部文件上传到静态网站服务。GitHub Pages 可将这些文件放在你自己的 用户名.github.io 仓库根目录，设置 Pages 从 main 分支根目录发布。

- 搜索、分类、文章阅读、深色模式均可直接使用。
- 写笔记保存在当前浏览器的本机存储。不会自动同步到 GitHub 或其他设备；清除浏览器数据会丢失记录，请使用“导出全部笔记”备份。
- 导入备份会合并未存在的笔记，相同 id 不覆盖。
- 默认三篇文章均明确标记为示例，可在阅读窗口中删除。
- 如需把新文章展示给所有访客，需要把文章数据加入 app.js 的 seed 数组并重新发布。当前版本没有远程登录发布服务。

## GitHub 发布

建议仓库名 cosmos-blog，设为 Public。将本目录中的文件提交到 main 分支，在仓库 Settings → Pages 中选择 Deploy from a branch、main、/(root)，保存后等待发布。

公开源码与公开网站是独立设置。此前的 Sites 预览仍保持私人访问。

## GitHub 自动同步与作者登录

网站使用 GitHub App OAuth 登录、Cloudflare Worker 账号白名单及 installation token 提交笔记。点击“作者登录”，仅 cosmos486 可获得上传权限，后台在每次上传时重新校验签名会话。仓库和写入文件固定，浏览器不能指定其他目标。无需输入个人访问令牌。登录会话仅保存在当前标签页会话，七天后失效。

新增、编辑时先保存本机，再自动上传到 data/notes.json；其他设备打开网页会读取公开笔记。旧笔记通过“上传本机已有笔记”加入队列。断网保留待上传内容，恢复网络或重新登录后重试。同一篇笔记云端有冲突时停止覆盖，保留本机内容。不同文章更新合并，并通过 GitHub 文件 SHA 避免并发覆盖。当前文件容量约 900 KB。删除按钮仅删除本机副本，导入备份后需要点击上传已有笔记。

网站已连接 https://cosmos-notes-api.1335624615.workers.dev 。后台认证代码适配自用户指定参考项目，保留在本地 worker 目录；密钥只放在 Cloudflare Secrets 中。GitHub Pages 仓库只发布网站前端，不包含任何密钥。
